# Extended examples

[`main.typ`](main.typ) is a complete bilingual thesis. Compile from the repository root:

```sh
typst compile --root . --input lang=zh contrib/main.typ
typst compile --root . --input lang=en contrib/main.typ
```

For multi-file editing in Tinymist, open `main.typ` and run `Typst Pin Main`.
